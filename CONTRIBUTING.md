# Contributing

Thank you for helping improve Rove.

This repository is primarily for public support, documentation, and issue tracking. It is not the private product source repository.

## Public contributions

Good contributions include:

- Clear bug reports
- Reproducible support questions
- Documentation fixes
- Feature requests with user value and scope boundaries
- Wiki improvements

## Before opening an issue

Please check existing open and closed issues first. If a similar issue exists, add relevant non-sensitive detail there instead of opening a duplicate.

## Keep public reports safe

Do not include private account data, credentials, sensitive diagnostics, private infrastructure details, billing details, or account-deletion requests in public GitHub content.

Prefer minimal reproduction steps and redacted screenshots.

## Product direction

Rove favors explicit, conservative behavior:

- No hidden command execution
- No silent command or configuration mutation
- No automatic collection of secrets, logs, clipboard contents, command history, or file contents
- Private support and public support remain separate

Feature requests should respect those boundaries unless a design change has been explicitly approved.

## Triage expectations

Issues may be labelled by type, status, priority, and platform. Public acceptance of an issue does not guarantee a release date.
