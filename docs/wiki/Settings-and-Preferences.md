# Settings and Preferences

Open Settings from the Host chooser or workspace header.

## Settings home

The settings home currently groups user-facing settings into:

- App preferences
- Keys / Identities
- Account / Access
- Workspace Backup
- Advanced

## App preferences

App preferences include:

- Language, including system default
- Theme mode
- General text size
- Terminal text size
- Font preset
- Contrast preset
- Host chooser grid tile size
- Browser view mode
- Browser grid tile size
- Show hidden files

After changing preferences, tap **Save**.

## Host chooser display

The Host chooser can be viewed as a list or grid. Grid size can also be changed through preferences or by pinch gestures where supported.

## Browser display

Browser preferences control list/grid mode, grid tile size, and hidden-file visibility. Browser sort is controlled in the Browser surface itself.

## Terminal display

Terminal text size is separate from the broader app text size. You can adjust it in App Preferences or by pinching in the Shell.

## Advanced settings

Advanced settings include deeper operational tools such as diagnostics, transfer/save behavior, notifications, security/trust overview, and paired editor entry points where available.

Advanced settings are intended for explicit user-controlled behavior, not hidden automation.
