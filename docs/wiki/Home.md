# Rove User Manual

Welcome to the Rove user manual.

Rove is a mobile-first SSH workspace for working with remote servers through a host chooser, SFTP browser, interactive shell, prepared-command Composer, Runner, app-native remote text editor, and optional cloud-service web/sync features.

## Important safety rule

Do not post private account information, credentials, sensitive diagnostics, private infrastructure details, billing details, account deletion requests, or security vulnerability details in public GitHub issues.

Use public GitHub issues only for public-safe bug reports, feature requests, documentation feedback, and general questions.
