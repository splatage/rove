# Getting Started

Rove opens to the Host chooser. From there you add or select a remote host, then work inside that host's workspace.

## Basic flow

1. Open Rove.
2. Tap **New host**.
3. Enter the host details.
4. Choose password or private-key authentication.
5. Tap **Save** to save the host, or **Connect** to save and open it immediately.
6. Once connected, use the workspace switcher to move between **Browser**, **Shell**, and **Composer**.

## Main areas

- **Host chooser**: your saved hosts and live workspace activity.
- **Browser**: remote SFTP-style file browsing and file operations.
- **Shell**: an interactive terminal for the selected host.
- **Composer**: prepare commands, save reusable commands, use variables, and run explicit Runner jobs.
- **Editor**: full-screen remote text editing from the Browser.
- **Settings**: preferences, keys, account/access, backup/sync, and advanced tools.

## Public support warning

When asking for help publicly, remove private host details, credentials, account details, and sensitive diagnostics first.

## What Rove is not

Rove is not a hidden automation tool or a full desktop IDE. Its core design is explicit: you choose what to connect to, what to edit, what to transfer, and what to run.
