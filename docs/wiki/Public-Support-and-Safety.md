# Public Support and Safety

This repository is public. Keep public support useful and safe.

## Use public GitHub issues for

- General bug reports
- Feature requests
- Documentation feedback
- Public questions that may help other users

## Do not post publicly

Do not post:

- Account deletion requests
- Billing or entitlement problems
- Purchase restoration details
- Security vulnerability details
- Credentials or secrets
- Private keys or passphrases
- Raw logs containing private details
- Full hostnames, server names, private paths, private usernames, or internal infrastructure details
- Screenshots that show private infrastructure or account data

## Redaction checklist

Before opening a public issue, remove or replace:

- Real server names and IP addresses
- Usernames
- Local and remote paths that identify private systems
- Tokens, cookies, keys, passwords, and passphrases
- Account identifiers and purchase details
- Customer or personal data

Use examples such as:

```text
example.com
user
/path/to/example
```

## Private support

Use Jarsoft private support or in-app private support flows for account deletion, billing, entitlement, purchase restoration, sensitive diagnostics, or security issues.

## Security reports

Do not disclose vulnerability details in public issues. Open a public issue only to ask for the private reporting route, without describing the vulnerability.
