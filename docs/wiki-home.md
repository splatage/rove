## Public support

Use public GitHub issues or discussions for general questions, bug reports, feature requests, and documentation feedback that are safe to share publicly.

Do not post private account information, credentials, sensitive diagnostics, private infrastructure details, billing details, account-deletion requests, or security vulnerability details publicly.
