# Support

This repository is for public, non-sensitive Rove support.

## Public support

Use GitHub issues or discussions for:

- Bug reports
- Feature requests
- Documentation corrections
- Public support questions

Before posting, remove private account details, credentials, sensitive diagnostics, and private infrastructure details.

## Private support

Do not use public GitHub issues for:

- Account deletion requests
- Billing or entitlement issues
- Purchase restoration problems
- Sensitive diagnostics
- Security reports
- Anything involving private account data

Private support details will be published through the Jarsoft website and the Rove app.

## Security reports

Security issues should not be filed publicly. See `SECURITY.md` for disclosure guidance.
