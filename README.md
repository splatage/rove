# Rove Support

Public support, documentation, and issue tracking for **Rove** by Jarsoft.

Rove is a mobile SSH/SFTP workspace for developers, sysadmins, homelab users, and server owners who need to keep their servers within reach while away from the office.

## What belongs here

Use this repository for public, non-sensitive Rove support:

- Bug reports that do not include private account or infrastructure details
- Feature requests
- Documentation corrections
- Public questions that may help other users
- Wiki/documentation improvements

## What does not belong here

Do not post private account information, credentials, sensitive diagnostics, private infrastructure details, billing details, or account-deletion requests in public GitHub issues, discussions, comments, screenshots, or attachments.

When in doubt, redact first.

## Private support

Private/account support should not be handled in public GitHub issues.

Use Jarsoft's private support channel for:

- Account deletion requests
- Billing or entitlement problems
- Purchase restoration issues
- Sensitive diagnostics
- Security reports
- Anything involving private account data

Private support details will be published on the Jarsoft website and in the Rove app as they become available.

## Public issue types

Use the issue forms provided by this repository:

- **Bug report** — something in Rove is not working as expected
- **Feature request** — a proposed improvement or new capability
- **Documentation issue** — documentation is unclear, incomplete, or wrong
- **Support question** — a public question that does not contain sensitive information

## Documentation

The `docs/` folder contains public documentation drafts and support policy material. GitHub Wiki content may be mirrored from these files once the wiki is enabled.

## Product boundaries

Rove should remain explicit and conservative:

- No hidden command execution
- No silent mutation of commands or configuration
- No automatic harvesting of secrets, logs, clipboard contents, command history, or file contents
- Private support and public support remain separate
